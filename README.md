# Struktur Data & Pemrograman Berorientasi Objek dengan Java

## Deskripsi Mata Kuliah
Mata kuliah Struktur Data dan Pemrograman Berorientasi Objek membahas konsep, teknik, dan praktik pemrograman untuk mengorganisasi, menyimpan, mengakses, dan memanipulasi data secara efisien dalam program komputer. Mahasiswa akan mempelajari berbagai struktur data seperti *linked list*, *stack*, *queue*, *hash table*, *map*, *tree*, dan *graph* beserta cara mengimplementasikannya dalam program.

Selain struktur data, mata kuliah ini juga membahas **Pemrograman Berorientasi Objek (PBO)**, termasuk konsep *class*, *object*, *attribute*, *method*, abstraksi, enkapsulasi, pewarisan, dan polimorfisme. Mahasiswa juga akan mempelajari cara memodelkan rancangan program menggunakan *class diagram* sebelum mengimplementasikannya ke dalam kode.

Pada akhir mata kuliah, mahasiswa diharapkan mampu memilih struktur data yang sesuai, menganalisis efisiensi algoritma menggunakan notasi Big-O, serta merancang dan mengimplementasikan program berbasis objek untuk menyelesaikan permasalahan komputasi secara terstruktur, efisien, dan mudah dikembangkan.

## Capaian Pembelajaran Mata Kuliah

- **CPMK 1**: Mahasiswa mampu menjelaskan dan mengimplementasikan berbagai struktur data, termasuk linked list, stack, queue, hash table, map, tree, dan graph untuk mendukung pengelolaan data dalam program.
- **CPMK 2**: Mahasiswa mampu menjelaskan dan mengimplementasikan konsep Pemrograman Berorientasi Objek, meliputi class, object, attribute, method, abstraksi, enkapsulasi, pewarisan, polimorfisme, dan pemodelan menggunakan class diagram.
- **CPMK 3**: Mahasiswa mampu menganalisis efisiensi struktur data menggunakan notasi Big-O untuk mengevaluasi kinerja operasi serta memilih struktur data yang sesuai dengan kebutuhan penyelesaian masalah.
- **CPMK 4**: Mahasiswa mampu merancang dan mengimplementasikan program menggunakan paradigma PBO dan struktur data yang sesuai untuk menyelesaikan permasalahan yang diberikan secara terstruktur.

## Topik yang Dibahas

- **Pemrograman Berorientasi Objek**: Konsep class, object, attribute, method, abstraksi, enkapsulasi, pewarisan, polimorfisme, dan pemodelan program menggunakan class diagram.
- **Struktur Data Dasar**: Linked list, stack, queue, hash table, dan map beserta implementasi operasi dasar dan analisis efisiensinya.
- **Tree**: Konsep struktur hierarkis, binary tree, binary search tree, traversal, serta penggunaan tree untuk pengorganisasian data.
- **Graph**: Representasi graph, traversal, pencarian jalur, dan penerapan graph untuk memodelkan relasi atau jaringan.

## Alur Pembelajaran

`PBO` → `Struktur Data Dasar` → `Tree` → `Graph`
